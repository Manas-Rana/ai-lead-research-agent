# Start Here

1. Install Node.js 20+.
2. Run `npm install`.
3. Run `npm run install:all`.
4. Copy `server/.env.example` to `server/.env`.
5. Add `OPENAI_API_KEY` for live research, or leave it blank for demo mode.
6. Run `npm run dev`.
7. Open http://localhost:5173.
8. Try `stripe.com` or use demo mode.

For submission, read `README.md` and `docs/architecture.md`.
